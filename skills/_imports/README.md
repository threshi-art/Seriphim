harvest artifacts remain tracked by hash in `../_registry/artifact-checksums.csv`.

licensing, security, tool compatibility, package structure, routing, and
synthetic behavior review. Reviewed packages live in functional categories, not
in this quarantine. No file under this directory may be named `SKILL.md`.
