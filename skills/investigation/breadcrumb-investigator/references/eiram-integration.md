# Ei R@M Integration

## Role

Breadcrumb Investigator is Ei R@M's external evidence acquisition, provenance, contradiction, and uncertainty layer.

It should run before high confidence psychological, ideological, legal, behavioral, or forecast conclusions that depend on disputed real world facts.

## Data contract into Ei R@M

Produce these fields conceptually, even when the final answer is prose:

- Event identity
- Chronology
- Actors and entities
- Jurisdiction
- Confirmed facts
- Corroborated facts
- Unresolved claims
- Contradictions
- Source provenance by evidence tier
- Dataset freshness and blind spots
- Alternative hypotheses
- Confidence by claim
- Missing decisive records
- Recommended next retrieval actions

## Ei R@M routing

Feed confirmed and corroborated facts into the relevant Ei R@M modules.

Feed unresolved claims only as hypotheses, never as facts.

Feed contradictions into deception detection, narrative divergence, Bayesian updating, and entropy analysis.

Feed chronology into temporal drift and trajectory modules.

Feed actor incentives into game theoretic analysis.

Feed missing evidence into uncertainty and collection planning.

## Guardrail

Analytical sophistication must not compensate for weak evidence. If the collection layer says "unresolved," downstream modules may estimate probabilities but must preserve that status.

## Orchestration prompt

Run Breadcrumb Investigator first as the evidence collection and validation layer. Reconstruct the event from all available lawful public traces, identify jurisdiction, build a source backed chronology, grade each claim by evidence tier and confidence, test alternative explanations, note stale or incomplete datasets, and identify missing decisive records. Then pass only confirmed and explicitly labeled corroborated facts into the full Ei R@M All Modules Orchestration Protocol. Pass unresolved claims as hypotheses with priors rather than facts. Use contradictions as inputs to deception detection, Bayesian updating, temporal drift, narrative analysis, game theoretic modeling, and entropy assessment. Produce the standard Ei R@M dashboard, plus an Evidence Integrity panel showing provenance, confidence, contradictions, collection gaps, and recommended next records.
