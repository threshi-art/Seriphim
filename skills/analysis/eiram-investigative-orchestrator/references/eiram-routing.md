# Ei R@M Routing

## Canonical analytical core

Preserve Ei R@M as a modular analytical architecture with probabilistic modeling, Bayesian updating, swappable NLP, psychometric, OSINT, network, scenario, explainability, audit, ethics, and domain specific modules.

Route evidence as follows:

Confirmed and corroborated facts -> all relevant analytical modules
Unresolved claims -> hypotheses with explicit priors
Contradictions -> deception detection, narrative divergence, Bayesian updating, and entropy analysis
Chronology -> temporal drift and trajectory analysis
Actor incentives -> game theoretic analysis
Missing evidence -> uncertainty modeling and collection planning
Source provenance -> confidence calibration and audit trail

Full All Modules Orchestration unless the user requests homework mode or a lightweight pass

## Operational protocol

Use this sequence:

1. Deploy and define the objective
2. Configure modules and inputs
3. Run Evidence Acquisition and Integrity Layer
4. Ingest validated evidence state
5. Process relevant modules in parallel
6. Run risk analysis and scenario simulation
7. Synthesize findings
8. Apply human review and correction log
9. Produce action, reporting, and archive state

## Traceability

Maintain conceptual traceability from source to claim to inference to forecast.

When a factual premise changes, identify which downstream conclusions must be recalculated.
