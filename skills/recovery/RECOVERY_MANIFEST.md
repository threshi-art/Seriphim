## Do not publish

- Raw conversations, private Agent instructions, memory, user dossiers, or
  personal writing-style calibration.
- Clinical instruments, psychological profiles, or person-level diagnostic
  workflows.
- Installed Skill archives or copied knowledge files whose license and source
  are not independently established.
- Claims that a Skill is packaged, installed, or tested when only a conversation
  report survives.
- Coercive collection or exploitation instructions.

## Recovery procedure

1. Export the original Skill package from its authoritative owner.
2. Compare its behavior with the public architecture and handoff contract.
3. Remove personal data, private memory, credentials, unavailable integrations,
   and copied source material.
4. Add deterministic synthetic routing, correction, false-activation, prompt
   injection, and blocked-action tests.
5. Review safety and redistribution rights line by line.
6. Publish in a dedicated pull request and only then mark the capability
   `packaged` and `public_package: true`.

Reconstruction is allowed only from approved public architecture with explicit
`reconstructed-public-edition` provenance. Conversation summaries alone do not
justify claims of historical fidelity or authoritative implementation.
