# Seraphim Development Skills

## Project Sovereignty Organizer

**Canonical skill path:** `/home/ubuntu/skills/project-sovereignty-organizer/SKILL.md`  
**Validation status:** Passed `quick_validate.py` on August 14, 2026.

Use this skill before organizing a complex project directory, creating recovery manifests, reconciling local and Git sources, or executing a non-destructive file migration. It requires an inventory and proposed move ledger before any move, preserves unknown and legacy material, excludes secrets from Git-related output, and uses counts, aggregate sizes, and SHA-256 hashes to detect discrepancies.

The skill is intentionally generic and can be used for Seraphim and other large project workspaces. The Windows/OneDrive execution portion remains pending until the desktop sidecar is available.
