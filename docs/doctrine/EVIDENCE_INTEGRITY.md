# Evidence Integrity Doctrine

Seraphim/EiRAM analysis may reason beyond direct observation, but it may never
silently promote an unresolved premise into an established fact.

## Evidence States

| State | Definition |
| --- | --- |
| `direct_observation` | Observable in the acquired source without accepting its narrative |
| `source_claim` | Asserted by a source but not independently established |
| `corroborated` | Supported by an independent evidentiary branch |
| `confirmed` | Established by authoritative or decisive evidence for the stated purpose |
| `inference` | Reasoned conclusion derived from identified evidence and assumptions |
| `unresolved` | Available evidence cannot settle the claim |
| `contradicted` | Reliable evidence materially conflicts with the claim |
| `missing` | Decisive evidence is unavailable, stale, inaccessible, or never collected |

These labels describe the state of a claim for a particular analytical purpose.
They are not permanent properties of a source or person.

## Independence

Ten reports repeating one original allegation remain one evidentiary branch.
Corroboration requires meaningful independence in origin, collection, or direct
knowledge. Search-result volume is not confidence.

## Dataset Freshness

Absence in a dataset supports a negative conclusion only when the dataset's
scope, jurisdiction, update date, and completeness cover the event. A database
ending before the event creates a collection gap, not proof that the event did
not occur.

## Inference Discipline

Every material inference identifies:

- supporting evidence;
- assumptions;
- plausible alternatives;
- confidence using calibrated language;
- evidence that would reverse or materially change the judgment.

Behavioral interpretation must remain distinguishable from diagnosis,
psychometric measurement, identity, intent, and dangerousness. Heuristic text
scores are features of the analyzed text, not validated measurements of a
person.

## Correction Log

When new evidence or user correction changes an assessment, the output states
what survived, what changed, why it changed, and what remains unresolved. Prior
language is not protected from revision.
