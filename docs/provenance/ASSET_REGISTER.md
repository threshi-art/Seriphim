# Public Asset Register

## Current decision

The curated source tree does not intentionally contain imported raster images,
audio, or video. Interface artwork uses source-controlled CSS, text, and icons
provided by declared package dependencies.

## Removed during the public review

- Four landing-page JPEGs with no recorded owner or redistribution basis.
- Eight System Sentinel icon images with no recorded owner or redistribution
  basis.
- Four referenced audio tracks that were not present in the repository and had
  no accompanying rights record.
- One externally loaded map image, replaced by an original CSS grid.
- The generated PDF copy of the Seraphim white paper; the Markdown source is
  authoritative.

These assets may only return after the owner, source, license or permission,
purpose, and removal path are recorded here.

## Dependency-provided assets

The web interface uses `lucide-react` icons and fonts or styles supplied by its
declared dependencies. Their licenses remain governed by the corresponding
packages and lockfiles.
