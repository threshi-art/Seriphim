# Implementation History

The files in `plans/` and `specs/` record how the public architecture and Skill
collection were curated. They are historical implementation records, not
runtime instructions, product requirements, or proof that a capability is
implemented.

The directory name records the planning workflow used during curation. The
Seraphim project does not copy or redistribute the Superpowers Skill library,
and its durable product architecture lives under `docs/architecture/`,
`docs/doctrine/`, `docs/safety/`, and `skills/`.

When a historical plan conflicts with the current manifest, package contents,
or public policy documents, the current artifact takes precedence.
