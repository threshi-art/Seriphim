# Seraphim Platform

Seraphim is a personalized, operator-controlled cognitive AI platform. The
authoritative product baseline is `SERAPHIM_WHITE_PAPER.md`; implementation and
safety rules are in `AGENTS.md`.

## Start here

| Need | Location |
|---|---|
| Product baseline | `SERAPHIM_WHITE_PAPER.md` |
| Agent and safety rules | `AGENTS.md` |
| Current version and changes | `versioning/` |
| Program assurance package | `docs/` |
| Web application | `client/`, `server/`, `shared/` |
| Desktop cockpit UI | `seraphim_desktop_companion/` |
| Windows desktop host | `desktop/SeraphimDesktopCompanion/` |
| Permissioned local bridge | `seraphim_local_bridge/` |
| Published applications | `dist/` |
| Historical and tool artifacts | `archive/` |

## Component map

### Primary platform

- `client/` — React Web Command Center.
- `server/` — Express/tRPC services and the legacy guarded local agent.
- `shared/` — contracts and reusable domain data.
- `drizzle/` — database schema and migrations.
- `docs/` — program, plans, requirements, design, verification, configuration,
  quality, and release records.

### Desktop system

The similarly named desktop directories are separate stages of one build:

```text
seraphim_desktop_companion/       React cockpit source
              |
              v
desktop/SeraphimDesktopCompanion/ C# WebView2 host and staged wwwroot
              |
              v
dist/desktop/                     Published one-click Windows package
```

Do not merge or rename these directories without updating
`scripts/build-desktop.ps1`.

### Companion applications

- `seraphim_local_bridge/` — FastAPI bridge with bounded workspace reads.
- `argus-vigil/` — local FastAPI network-analysis companion.
- `SystemSentinel/` — Java/PowerShell Windows health application.
- `Geospatial Command/` — legacy geospatial HTML prototypes retained for
  reference.

### Runtime and generated material

- `node_modules/`, `**/bin/`, `**/obj/`, `**/target/` — regenerated by package
  or build tools.
- `dist/` — generated release output, intentionally retained for one-click use.
- `.seraphim-agent/`, `.manus/`, `.manus-logs/`, `logs/` — local runtime or
  tool records; inspect before removing.
- `archive/` — non-authoritative snapshots, scratch packages, and loose legacy
  artifacts.

## Common commands

From this directory:

```powershell
pnpm dev
pnpm verify
pnpm desktop:build
```

The one-click desktop entry point is:

```text
START_SERAPHIM_DESKTOP.bat
```

Commands and generated code are subject to the approval rules in `AGENTS.md`.
