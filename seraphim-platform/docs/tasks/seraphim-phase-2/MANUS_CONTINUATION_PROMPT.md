# Manus Continuation Protocol

Work from current `main` and the next dependency-unblocked Gate task. Before mutation, fetch and reconcile the repository, inspect instructions and current task handoff, use an isolated branch, map requirements to tests, and preserve completed Gate 1 work.

Implement narrowly. Use production local Runtime storage only beneath `%LOCALAPPDATA%\Seraphim\Runtime`; use `:memory:` or temporary directories for tests. Never write durable Runtime state into Git, a repository, a workspace, or the OneDrive source tree. Build, run, attack, inspect, repair, verify, publish evidence, and continue.

Do not create a generic shell endpoint, direct arbitrary SQL endpoint, unbounded export, silent Desktop mock fallback, production file write, or external execution capability. Preserve disabled-by-default production file writes until Gate 2 passes and explicit operator activation occurs. Preserve disabled-by-default execution until Gate 3 passes and explicit operator activation occurs.

At a genuine destructive, irreversible, security-boundary, credential, or explicit operator gate, report the exact evidence and required decision. Otherwise continue sequentially. Independent Codex review is deferred assurance during Phase 2 development and required for production activation or release unless specifically waived.
