# Agent Cortex

Each named capability is a **cognitive region under Seraphim**, not a sovereign peer or unbounded executor.

| Region | Primary role | May produce | Must not do autonomously |
|---|---|---|---|
| Athena | Strategic planning, decomposition, priority arbitration. | Mission and planning signals. | Override operator policy. |
| Manus | Implementation, tests, repair, bounded automation. | Engineering and verification signals. | Expand execution authority. |
| EiRAM | Evidence analysis, competing hypotheses, causal and narrative analysis. | Analytic signals. | Treat inference as fact. |
| Mnemosyne | Episodic/semantic memory, open loops, recurrence. | Memory and recurrence signals. | Execute recurrence proposals. |
| Hermes | Web, document, API, browser, speech, and vision normalization. | Source-normalized signals. | Trust unverified external input. |
| Argus | Policy, approval, audit, privacy, provenance, and replay resistance. | Boundary and risk signals. | Waive hard controls. |
| Hephaestus | Architecture, repository, requirements, build, and testing systems. | Technical design signals. | Bypass Git or acceptance evidence. |

Every region may disagree, abstain, fail, or request more evidence. Seraphim records the field of signals and independently decides whether to accept, reject, merge, challenge, defer, seek more evidence, override, or use executive intuition.
