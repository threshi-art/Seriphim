# Memory and Recurrence

Phase 2E memory captures what happened, when, why it mattered, what changed, unresolved state, confidence, related evidence, and later reactivation conditions. Required temporal relations include `before`, `after`, `caused`, `contradicted`, `reinforced`, `superseded`, `resolved`, `still_open`, `predicted`, `observed`, and `related_to`.

## Required Objects

- Episodic and semantic memory.
- Mission and task history.
- Open loops and attention items.
- Recurrence triggers and material state changes.
- Predictions, outcomes, corrections, calibration, archival, and operator forgetting.

## Canonical Recurrence Scenario

An apple observed at location X is stored with time, source, significance, and location. A later absence is linked to the observation, classified as a material state change, and reactivates the prior matter. Mnemosyne proposes the reactivated matter; Seraphim decides whether it matters. The decision and later outcome update memory and calibration. Recurrence and open loops survive restart but produce proposed work only.
